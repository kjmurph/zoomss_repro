# Baseline Diagnostics — ZooMSS Energy Budget Revision

## Purpose

These baseline outputs were generated from the **unmodified** ZooMSS model prior to implementing the revised energy budget framework. They serve as calibration targets for Phases 1–3 of the revision.

## Git Reference

- **Branch:** `feature/energy-budget-revision`
- **Commit:** `d07b5ab` (identical to `upstream/main` at time of baseline)
- **Date:** 2026-02-13

## Model Configuration

- **Simulation length:** 100 years
- **Time step (dt):** 0.1 years
- **Save frequency (isave):** 2 (every 0.2 years)
- **Functional groups:** 12 (9 zooplankton + 3 fish), default `GroupInputs`
- **Forcing:** Static (no seasonal variation)
- **Equilibrium averaging:** Final 10 years

## Environmental Gradient

30 grid cells spanning:

| Parameter | Values |
|-----------|--------|
| **SST** | 5, 10, 15, 20, 25, 30 °C |
| **Chlorophyll a** | 0.05, 0.15, 0.5, 1.5, 5.0 mg/m³ |

## Files

| File | Description |
|------|-------------|
| `baseline_reference.rds` | Complete numerical reference (N, gg, Z, biomass for all 30 runs + Groups) |
| `baseline_biomass_summary.csv` | Total wet-weight biomass by group for each SST × chl combination |
| `baseline_size_spectra.pdf` | Abundance size spectra at low/moderate/high productivity (SST=20°C) |
| `baseline_growth_rates.pdf` | Mass-specific growth rate profiles for all 12 groups (SST=20°C, chl=0.5) |
| `baseline_predation_mortality.pdf` | Total mortality profiles for all 12 groups (SST=20°C, chl=0.5) |
| `baseline_biomass_vs_sst.pdf` | Biomass by group along SST gradient (chl=0.5) |
| `baseline_biomass_vs_chl.pdf` | Biomass by group along chlorophyll gradient (SST=20°C) |
| `baseline_proportion_vs_sst.pdf` | Community composition (proportional biomass) along SST gradient |
| `baseline_proportion_vs_chl.pdf` | Community composition along chlorophyll gradient |

## Loading the Baseline Data

```r
baseline <- readRDS("baseline_diagnostics/baseline_reference.rds")

# Primary reference (SST=20°C, chl=0.5 mg/m³)
baseline$gg         # Equilibrium growth rates (12 × 191)
baseline$N          # Equilibrium abundances (12 × 191)
baseline$Z          # Equilibrium mortality (12 × 191)
baseline$total_biomass  # Total biomass per group (length 12)
baseline$w          # Weight grid (length 191)

# Full gradient
baseline$all_results[["sst15_chl1.5"]]  # Access any run by ID
baseline$summary    # Data frame of all biomass summaries
```

## Verification Targets for Phase 1

After implementing the new energy budget with `MetabConst = 0` and `Kappa = 1`:

- `model$assim_eff[1, 1]` should equal `0.75 × 0.15 = 0.1125` (not `0.375`)
- Equilibrium size spectra will differ from baseline (expected — assimilation values change)
- Growth rates will be higher for most groups (α_j × C_j / C_i > 2.5 × C_j before maintenance)

## Verification Targets for Phase 2

After calibrating `MetabConst` and `Kappa`:

- Equilibrium size spectra should match baseline within ~5–10%
- Total biomass by group should be comparable
- No starvation mortality at equilibrium under typical conditions
